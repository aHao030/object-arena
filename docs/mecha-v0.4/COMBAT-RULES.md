# 机体对战规则 m0.1

以下数值为设计默认，未经过平衡或真机验证。所有比赛在开始前冻结完整规则与资产版本。

## 动力学与动作的明确边界

采用“受力根体＋受控动作”的混合方案。根体受重力、地面接触、有限驱动、碰撞冲量和推进力影响；地面电机只能在有效接触时驱动，速度控制器通过受限力逼近目标，不直接每帧设位置。制动消散能量，不倒生能源；空中仅由推进模块提供主动运动。

步态、瞄准、挥刃与自平衡是平台控制系统，不是从照片推断出的机械。其动作速度、姿态恢复、允许转向与碰撞形状由统一规则限制；这是可解释的游戏近似，不承诺工程级双足平衡、装甲强度预测或全物理关节仿真。首发不使用自由布娃娃控制战斗中的机体。

使用SI单位和9.81m/s²重力；统一2.2m参考高度，允许的身体包络和比例区间由机架版本定义。标准总质量目标180kg，上限240kg；可选模块/装甲定义质量，玩家不能手填战斗质量。视觉LOD不改变根体或部位判定。

根体碰撞代理用于移动和掩体接触；头/躯干/四肢/背包的受控部位代理用于命中。首发不让每片甲自由碰撞求解，双方角色接触按根体处理；部位代理必须覆盖可造成命中的可见主体，并与标准动作一致。不能让动画摆出掩体外射击姿态而服务器仍从掩体内命中。

## 移动与推进

方向移动、转向/镜头、短时喷射、升空、射击、近战、防御是首发动作。地面目标速度上限6m/s，喷射速度上限12m/s，机体转向上限180°/s；通过受限力与软阻力包络实现，不依赖渲染帧率。最高速度是控制目标，不把被击退的速度突然截断为零。moveX/Z按机体偏航的局部水平坐标；boost启用喷射，lift表达升空意图，合成(moveX,lift?1:0,moveZ)后归一化；全零而boost为真时向机体前方喷射。lift本身不启用喷射，aimPitch不改变推进方向，关闭喷射靠重力下降。

标准地面驱动力上限1,200N、电输入上限6kW，按效率与速度同时限制，低速受力上限而非除以零；牵引不得超过有效接触的摩擦反力。标准背包喷射合力上限3,000N，高推力3,600N，合力按输入归一化分配；同时要求对根体产生的正机械功率max(F·v,0)≤0.8×本tick实际推进电输入，超出时降低推力。在12m/s顺向运动时标准背包最多800N，而非继续3,000N。包含抵消重力分量，空中无免费升力；装饰翅膀无功能。

能量池50kJ，标准推进12kW、高推力14kW；地面机械功按0.8效率折算电输入，机架基础控制0.5kW包含待机与姿态辅助。扶正力矩最大1,200N·m且正机械功≤400W；地面依赖接触，空中只允许仍有功能且分到功率的推进模块提供姿态控制，不能失去背包还免费扶正。它是简化控制辅助，不模拟完整腿部/推进工质。总线硬上限20kW，持续充能与维持动作都计入每tick负载；具体优先序与预留见技术合同。

关闭喷射且过去1秒没有武器动作时，反应堆可按3kW给未占用能量容量充电，每秒额外+4热；这是公开科幻供能规则。热量0–100，≥100进入过热锁，降到60后解除。标准/高推力喷射分别每秒+15/+20，步枪每发+8，近战每次+12；基础散热每秒10，反应堆运行时净散热6。

每tick先结算连续动作的能量/热量并检查过热，再检查此前已充能动作能否完成；合法完成时先提交攻击、再加该攻击热量并立即检查过热。H=95时完成步枪会先发弹再因103进入过热；若本步先被持续喷射加到100则取消尚未提交的充能。取消退未消耗预留，已消耗不退，原动作冷却不提前刷新；已提交弹丸继续存在。散热最后结算，不能靠同tick散热规避刚触发的过热锁。

## 武器和防御

首发脉冲步枪采用服务器弹丸，不是瞬时射线：速度45m/s，寿命2秒，发射间隔0.25秒，每发消耗500J，对有效部位造成35点规则伤害。枪口与射线路径均检查遮挡，不能从镜头或墙内生成弹丸。扫掠检测防止固定步长下穿过薄掩体。

脉冲颜色与光效为表现，伤害是游戏抽象，不声称模拟真实激光烧蚀。客户端只发送开火意图；初始版本不回溯修改历史命中，不用客户端报告命中结果。高延迟导致体验变差时限制匹配区域和提示，不给客户端任意时间戳补偿。

标准近战刃有效长度0.8m，完整动作周期1.2秒，激活窗口和扫掠轨迹由服务器动作曲线定义，每次900J、90点伤害。相同attackId对同一目标最多结算一次，持键或高帧率不能增加命中。外观很长的刀不会获得额外范围。

副手护盾有300点屏障值，防御消耗每秒1kJ，只有激活且覆盖当前攻击路径时拦截步枪与近战，背后命中不受保护；不得藏入躯干或跨越掩体。屏障按命中事件稳定顺序逐次消耗，吸收min(剩余屏障,本次伤害)，剩余伤害继续沿合法路径查身体，不凭空指定一个部位。盾失效本局不修复，未激活不提供屏障。

同tick按接触子步时间、攻击者ID、attackId、弹丸ID排序处理命中。例：盾剩20，同tick先后两次35点且路径均击中身体，先一发吸收20后剩15，后一发剩35；再分别对身体应用装甲折扣与部位传伤，不能每发重新获得20屏障。

## 部位失能与胜负

核心完整性1,000；头和躯干代理都映射核心，没有未定义的独立头部HP；每条手臂150、每条腿200、推进背包120。先扣屏障，再对身体剩余伤害应用装甲系数，最后命中核心直接扣核心，命中非核心扣该部位并将该次身体伤害25%传给核心。已失能部位仍按同样25%传伤，HP保持0；不额外把过量伤害再加一次。全部伤害以千分之一点的整数表示，每次装甲折扣和核心传伤分别向下取整，HP不小于0。

同一弹丸只对最先有效身体部位结算一次；同距按固定部位ID，不能重复扣多个部位。屏障吸收后若仍有伤害且还未接触身体，弹丸带剩余伤害继续本步剩余轨迹/后续轨迹，直到命中或原寿命结束；屏障不是可重复刷伤的身体部位。近战同attackId对目标的屏障/身体合并为一次攻击判定，不能跨帧重复消耗屏障。

右臂为0停用步枪和右臂内置刃，左臂为0停用护盾；单腿失能地面速度/驱动力为50%，双腿失能为0但合法推进器仍可工作；背包为0停用喷射。首发失能部位始终保留可见、不透明的受损实体与相同代理，停止功能但不隐藏，不产生额外碰撞碎片或永久损坏源模型。脱落仅作未来独立规则研究，不能留下隐形命中体。

1v1、180秒、48×48m有边界场地，首发是私密/休闲对战。核心为0、主动退出或累计失联耗尽产生lose；同一物理步先完成所有已合法产生的命中与状态更新，再收集双方lose：单方lose判负、双方lose平局；无人lose且时间到，比核心剩余百分比，相同则平局。最后一完整物理步的命中计入；终局一旦持久化不被迟到输入改写。

场地边界为阻挡墙，升空高度上限12m由顶部阻挡与推进控制限制，不用瞬移回场；不沿用旧版推台出界规则。出生位置对称且无穿透。每人每局累计失联15秒，输入250ms无更新即归零；连接断开或心跳超2秒进入失联并回溯最后心跳，重连不重置预算。

## 装配预算与成本分离

竞技预算CP来自固定机架基础值和模块目录：基础机架20，轻装甲10/标准装甲20，脉冲步枪20，内置近战刃10，护盾10，标准背包15/高推力背包25。标准装配合计95；任何组合CP≤100，总质量≤240kg，峰值功率≤20kW，还须满足每个插槽允许的质量、包络和朝向。

高推力背包若导致105CP，须换轻装甲变为95；它同时增加质量和功耗，并非免费升级。上述目录只是初始可解释示例，模块完整机械参数须以冻结目录提供，不能只列CP忽略功率/质量。

用户外观适配到同一等级机架和插槽包络；不按原图像素、导入文件单位或塑料重量赠送能力。超长炮、超宽翅膀不能在预算内偷偷扩大命中/遮挡优势；代理适配失败只可留在展示或单独实验规则。开放任意几何对抗须另立规则，不混入本级比赛。

真实API用量、资产处理PC与竞技CP分开。付费可提高生成质量或处理额度，不能提高100CP上限、战斗伤害或反应堆能力；比赛热路径不调用大模型。
