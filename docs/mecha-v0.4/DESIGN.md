# 制作、驾驶、改装、再挑战

这是产品交互与机体系统设计；根目录DESIGN.md记录的是旧网页视觉系统，两者用途不同。

## 玩家会经历什么

玩家先用预置机体打一场短训练，理解移动、射击、近战、喷射和能量。随后进入机库带入自己的模型，确认分件和关节，选择功能模块；在动作预览和试验场发现问题，修改后发布不可变机体版本，再邀请朋友对战。赛后回放展示命中、热量、模块失能和关键操作，帮助玩家决定下一次改装。

机库是核心，不是上传完成页。首屏呈现机体、当前插槽、装配清单、超额原因与动作预览。对战HUD优先显示机体完整性、能量/热量、武器状态、目标与网络状态。展示柜与战斗入口分开，不能把漂亮预览称为可参战。

## 三条输入路线，不给相同保证

| 输入 | 首发处理 | 达到可驾驶的条件 |
|---|---|---|
| 已分件GLB或合格的带骨架GLB | 检查节点/骨架、映射标准身体段、烘焙安全变换 | 用户确认关节，动作测试通过，几何覆盖/模块限制通过 |
| 整体GLB/STL | whole-body路线先分件；或用户主动选择core-shell路线 | whole-body要正确身体段；core-shell无需切手脚，按下述核心装配校验；STL无纹理 |
| 照片 | 裁剪、确认主体、图像转3D，再做分件候选与绑定 | 不可见结构是推测；用户修正后通过同一动作/几何验收 |

第一版输入可接受任意主题的合法模型，但驾驶模板只覆盖人形。whole-body保留原机体分段；core-shell把杯子、石头等原模型变成可见的躯干外壳，平台补齐可见的标准机架头、手臂和腿，再装武器/背包。这是真正可驾驶的装配路线，而非挂饰或四轮底座；不声称原杯子被自动切出了关节。

core-shell的完整步骤：选择路线→确认来源模型与躯干槽→查看缩放/裁剪前后对照→将外壳刚性绑定躯干→保留标准实体结构与受击主体可见→完成同一套步行/瞄准/喷射检查→选择规则模块与预算→发布→试射/私密对战。无需分件服务即可走通。外壳不得改变标准受击体和装甲功能；功能仍来自选择的装甲模块。whole-body失败只能提示此选项，不自动转换；改路线会使旧映射确认失效，并重新绑定报价，既有产物可复用且不因切路线自动调用收费服务。

单张照片不能确定背面、真实骨架、关节轴或武器性能。允许补拍正/侧/背参考图；支持多图的具体适配器才会接收多图，不能把单图API称为多视角重建。默认先给低成本草稿，不未经确认反复收费修复。

## 硬表面机体的可动化

标准机架包括骨盆/躯干、头部、左右上臂/前臂、左右大腿/小腿与足部。编辑器展示前后方向与关节标记，用户确认肩、肘、髋、膝等关键点、旋转轴和范围。装甲刚性绑定所属骨段，不用柔性蒙皮把金属板拉弯。

预览必须覆盖待机、步行、瞄准、挥刃和喷射。检测缺段、错误左右、严重穿插、脱离关节、模块越界和视野遮挡。自动建议不合格时停在draft，说明可修位置；用户可以保存导出产物、补充输入或明确接受简化模板。不能静默替换外观后声称还原成功。

兼容的已有骨架可以复用，但不执行用户提供的脚本、动画事件或任意物理配置；映射到平台受控骨架和动作，外部动画仅作预览候选，不能决定攻击速度。

## “我的机体”不只是一层皮肤

外观归玩家，动作与机械能力由可验证的机架及模块赋予。首发插槽是主手武器、副手护盾、背部推进器，以及机架的身体装甲分组；每个插槽最多一个模块，用户模型的一把枪必须映射到平台某种武器才获得功能。

改装实际改变模块质量、功率需求、能量消耗、热量、冷却时间和可用动作。首发可选轻/标准装甲、标准/高推力背包，主手固定脉冲步枪；不承诺尚无完整目录的外置近战主武器。右臂内置一把标准近战刃、不另占主手槽但计质量/CP，与步枪共享攻击动作通道，不能同时充能/出招或复制出额外通道。右臂失能同时停用步枪与内置刃，左臂失能停用护盾。

外形差异也必须如实显示：玩家会看到比赛用代理，而不是允许模型画一个巨盾却没有对应判定，或画一根很长的炮管却从躯干穿墙开火。超出模块允许包络的外观须缩放、裁剪或只在展示柜使用。修复要由用户确认。

## 从模型尺度到作战尺度

保留扫描尺寸与校准来源，但首发统一映射到2.2m高的人形作战机架。现实0.18m塑料模型的质量不直接变成虚拟机甲质量，也不根据原作设定送出几十吨或无限能源。

作战质量来自标准机架、装甲和模块的服务器定义。用户的现实材料与几何资料用于制作说明和可视化，不默认成为虚拟装甲强度或伤害倍率。界面明确“模型资料”与“作战参数”的区别。将来若做模型原尺寸物理赛，单独建立规则，不能混排。

## 玩家可设置的边界

可改外观配色、允许范围内的身体比例、模块搭配、插槽朝向的合法微调、操控键位、镜头、触屏布局与辅助开关。比例或装配改动重新计算代理、动作适配和预算并产生新版本。

不能自由填写无限射程、伤害、摩擦、能源、关节强度或命中盒大小。自带API可提建议和生成资产，最终的功能选择与参数必须经过服务器规则校验。
