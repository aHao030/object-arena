# 机体方向的质询、修订和复核

日期2026-11-11。范围是设计文件与可实施合同，不是已实现平台、真人试玩或性能测试。

## 第1轮：真实用户确认方向

用户明确参照高达创战者，并回答两个实质问题：优先把自己的照片/模型变成可驾驶机体再改装对战；规则统一可解释，允许受限推进器和科幻武器。旧底座推台只是此前默认，现已替代。

据此建立机库→可动化确认→装配→试驾/试射→对战→回放再改装主循环；扫描尺度与作战参数分开，预置机体原型不替代用户资产闭环。

## 第3轮：独立复核

模型/BYOK审阅者确认其6项闭合、未发现本范围新增P0/P1；跨端审阅者确认其3项关闭、无新增P0/P1；物理审阅者确认原3项关闭，但补出一个协议问题：同seq同时fire/melee为真时如何竞争共享通道。

追加修订：fire持键按合法冷却请求，melee只在上升沿触发；同seq近战优先、步枪不排队补发；通道忙时近战丢弃并提示，需松开再按。attackId由服务器生成，C13验证。随后物理审阅者只对这条修订定点复核，结论resolved。

这些结论只证明已提出的文档问题得到处理，不证明没有未发现问题，更不表示功能可发布。
