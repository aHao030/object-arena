# 物竞场 v0.4：把自己的模型变成可驾驶机体

日期：2026-11-11。当前有效方向。v0.3物体底座推台与线上展示保留为历史原型，不能代表本版玩法已经实现。

## 用户已经确认

核心体验是“自己拍摄或导入的模型 → 可驾驶机体 → 改装 → 实时对战”。物理采用统一、可解释的规则，允许受限推进器和科幻武器。继续保留手机/电脑/平板、自带模型API和透明费用的原要求。

## 重新定义项目

制作属于自己的机体，选择机架、武器、护盾和推进背包，在3D场地中驾驶、射击、近战与短时喷射。玩家的设计通过模块组合影响性能；驾驶技术通过走位、瞄准、能量管理和攻击时机影响结果。

本项目借鉴“制作自己的模型并驾驶它对战”的体验，不制作动画中的现实物质驱动装置，不默认分发官方机体、角色、商标或音乐。首发使用原创或明确可用资产。

## 第一版的可交付边界

- 一个标准人形机架，支持自己的分件GLB映射与确认；整体模型走分件/人工辅助，照片走生成草稿。
- 模块化机库、动作验收、武器和背包插槽、试验场、1v1私密对战、服务器结算和回放。
- 平面场地、有限掩体、地面移动、短时喷射/升空、脉冲步枪、近战刃和护盾。
- 首发不做任意形态自动适配、无限飞行、自由定义武器伤害、全物理双足平衡、任意碎裂和大规模战场。

首个可玩原型必须先让两台原创预置机体完成移动、瞄准、射击、近战、喷射、结算；紧随其后的门槛是用户自己的分件模型能够真正动起来。照片最终路线保留，但不假装单图可稳定完成全部可动化。

## 尚需原型回答

照片分件和刚性绑定成功率；双足动作的视觉穿插容差；移动端锁定辅助的手感；虚拟模块的质量/能量标定；低端手机运行预算；实际模型费用及地域可用性。所有数字均是初始设计值，没有实测支持名单或工期承诺。
