# 自带模型 API（BYOK）

“填一个 API 地址”不代表已经支持任意模型。必须通过协议与能力检测；通用对话接口不能天然输出 3D 网格。

## 三类能力

| 能力 | 输入/输出 | 接入方式 |
|---|---|---|
| vision-analysis | 图像 → 结构化建议 | 优先提供受限 OpenAI-compatible chat 协议适配器；逐项检测图像与 JSON 能力 |
| image-to-3d | 图像 → 异步任务 → mesh/GLB | 供应商专用适配器或平台定义的 HTTP 适配器，不能假定 OpenAI 兼容 |
| asset-description | 档案 → 文本 | 可选文本接口；不授予修改物理裁判的能力 |

用户可以只连接 vision API 并使用预置/导入网格；没有 image-to-3d 能力时明确显示“缺少 3D 生成服务”，不给一个假的成功物体。

## 配置与交互

用户填写配置名、HTTPS 基础地址、模型名、能力类型和密钥；界面解释会把哪些图片发给该供应商。保存后只返回掩码、凭证 ID、已验证能力和计费模式，不回显密钥。

连接测试先做低成本能力请求，显示可能产生费用；不默认发送用户原图或高成本生成。适配器应支持 `probe`、`quote`、`submit`、`poll`、可选 `cancel` 和 `usage`，输出统一的错误分类及 requestId。

生成前允许人工裁剪并确认一个主体，建议单物体、清楚轮廓并去除私人背景；展示实际发送图片、供应商、输出质量、平台硬上限、第三方上限/估计值和取消语义。裁剪或改输入使旧报价失效。只有选择“生成”才发送图像，不在编辑参数时自动调用。

先要求目标尺寸与质量/材质预检，已知超出硬上限时先修正再收费。此时只给初估CP，说明可能生成失败或无法得到合格代理；生成后才确认实际代理与精确CP。生成成功但参赛校验失败时，用户可私有预览、下载合规输出和查看原因；可简化或重新校准，重新生成须新报价，不承诺供应商退款。

## 凭证与地址安全

- 密钥仅发送到平台后端，使用独立密钥服务/信封加密保存；解密仅授权给代理执行过程。数据库只存引用与掩码，不得写入普通 JSON 配置。
- 生产 BYOK 首发仅接已审核供应商域名。用户自定义域名须经平台批准或独立部署管理员加入允许列表，不允许随意填 localhost、内网 IP、云元数据地址或任意 HTTP URL。
- 每次调用重新解析 DNS 并检查所有地址，包括 IPv4/IPv6、私网、回环、链路本地与保留段；连接到已经验证的目标，防止解析与连接之间的重绑定。默认禁用重定向；确需跳转必须逐跳重验并禁止跨域传递凭证。
- 下载产物也执行同样出网策略；只允许适配器约定的 HTTPS 对象域名，限制 MIME、总字节数和时长，不能把模型返回的 URL 当可信地址。
- 本机模型 API 如 Ollama/局域网服务属于单独的本地桥接部署路线，不通过公网服务器访问 127.0.0.1；首发托管版不承诺支持。
- 每用户、每凭证和每供应商限流；凭证撤销立即阻止新请求。已提交任务只能尽力取消，撤销不保证上游退款。

## 状态、幂等与失败

生成操作：quoted → reserved → submitted → processing → validating → succeeded；也可 failed/cancelled/unknown。未知表示供应商可能已执行，必须查询/对账后才能发起第二次收费提交。

平台接受同一用户相同幂等键仅创建一次操作，并保存请求摘要；同键不同参数返回冲突。quote与operation一对一，每个操作首发最多一次收费提交，不同幂等键不能重用报价。上游支持幂等时沿用稳定键；不支持时，对收费超时请求禁止自动重发。轮询可退避重试，输出无效只给失败和已发生用量，不自动再买一次。连接测试遵循相同的hard/estimate/unknown授权策略；未知计费仅可做无费元数据查询。

错误示例：credential_rejected、capability_missing、budget_exceeded、rate_limited、provider_timeout、result_unknown、invalid_geometry、unsafe_output_url。用户可理解错误和下一步，密钥与上游原始错误头不外泄。

## 物理参数隔离

模型返回的材料、尺寸和质量均为建议，保存出处与置信说明。服务端使用严格字段白名单、数值范围和 JSON 校验；文案中的“质量无限”“忽略规则”等不参与执行。视觉 PBR 金属度不是物理密度，模型不能改变 CP 或裁判。

## 开发适配器合同

`probe` 返回能力、支持格式、最大输入数/字节数、异步模式、幂等能力、计价单位、取消语义。

`quote` 返回平台可执行的资源上限与第三方费用约束等级：hard / estimate / unknown。`submit` 只能引用本用户已授权资产与凭证，返回平台 operationId；`poll` 汇总供应商状态；产物仍须经独立资产校验，不能直接成为参赛版本。

新供应商适配器上线前必须验证：无效密钥、图像能力缺失、任务超时、重复响应、畸形网格、计费结果未知、恶意 URL 和撤销凭证后的行为。具体模型名和价格通过当前供应商能力获取，不在设计文档硬编码。
