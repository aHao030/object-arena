# 从玩家视角看首发流程

这是交互行为草案，不是已经存在的界面。短路径先让用户验证“好不好玩”，再决定是否花钱生成。

## 第一次来

首页先提供“用示例物体练习”“导入模型”“拍照制作”。无需填写模型密钥即可用合规示例体验，登录后才能长期保存私人资产和加入受权限保护的私密对局。账号实现使用标准会话与身份适配层，具体身份供应商在部署时选择，不把API密钥当登录凭证。

进入练习前测试实际WebGL2、WASM资源与连接。失败时解释“这个浏览器暂时无法进入3D比赛”，保留资料和任务页面，提供重新检测；不把安装PWA或开启WebGPU作为必要步骤。

## 我用手机拍一只杯子

1. 选拍照或相册；拒绝相机权限仍可继续选文件。
2. 裁剪杯子并确认实际将发送的图片。提示减少手、其他物品和私人背景，说明不可见的背面将由模型推测。
3. 填一个已知长度，选实心/空心和质量依据。尚不知道精确几何时显示初估预算，不显示假的代理。
4. 选择有image-to-3d能力的服务。只有图像分析API时明确缺少3D服务，提供配置或导入替代入口。
5. 查看平台硬上限、第三方硬上限或估计价、取消语义及生成失败可能已收费的说明，点击后才提交。
6. 关页后任务继续，不重复购买；另一设备可以查询已有任务。
7. 生成后检查真实输出、尺寸、质量来源与代理，做固定对中装配。生成成功却不可参赛时仍可保存合规输出、看具体失败原因，选择简化/校准或新报价重做。
8. 查看精确CP、动力和电量，练习翻倒和推挤；通过校验才发布不可变版本。

## 我已经有模型

首发入口明确“静态GLB / STL”。动画、骨骼和morph要求在建模软件烘焙后再导入；STL先选单位，使用已知长度复核。导入清洗无需调用模型时不收虚构token费。预览显示代理与真实外观的区别，特别提醒杯口和把手是否被填平。

## 我和朋友打一局

我选择已发布装配创建私密房间，复制短期邀请链接给朋友。平台不替我发送消息。朋友登录并用自己的合格装配加入；双方加载资源、准备后倒计时。

电脑可重绑键位；手机提供方形映射摇杆/独立控制与刹车，均可同时满油门满转向。低画质不改变规则，竖屏不减少有效战场信息。对局开始前提示切后台不会暂停对手，失联会累计消耗15秒预算。

出界、主动退出、失联和超时都按公开规则结算。结束页显示原因、冻结规则、自己的动力/电量变化及回放入口，不用大模型故事代替裁判证据。

## 我不想继续保留资料

资产详情提供删除和凭证撤销。删除立即禁止新使用和迟到结果重新出现；明确显示正在比赛、最小裁判证据及备份的保留例外与截止时间。平台删除不能保证供应商已经删除其收到的图像，生成前就应说明这条数据流。
