# 组合驾驶与玩家可修改键位

用户最终指定鼠标视角、WASD移动、Space升空、Shift加速、左键射击、Q/E/R/T技能槽与玩家改键。替代0008的Q推进/Shift缓行键位选择，不改变服务器mecha-slice-0.3物理或资源规则。

Space短按使用原有限起跳、保持后有限升空；C缓行。技能槽全部未装备，不凭按钮生成能力。玩家可重绑移动、跳跃/升空、推进、缓行和四空槽；鼠标左键固定射击，箭头保留备用。冲突与浏览器保留键拒绝。来源独立持有使移动、视角、推进与射击并行。

偏好只保存在当前设备，损坏配置回默认，写入失败明确提示仅当前页生效。设置期间冻结驾驶方向和动作意图，机体仍受惯性、重力及对战影响；离开捕获按钮取消待录键，不抢输入框/其他按钮。取舍是没有跨设备账户同步、鼠标重绑、多键宏或任意组合键；后续装备接入后沿用四槽，不代表现已实现护盾/近战。
