# 相机方向行走与有限推进机动

用户在2026-11-11确认Minecraft键鼠骨架、偏EXVS快速机动。规则mecha-slice-0.3采用相机yaw选择线性运动方向，机体/武器仍按服务器限速旋转；这允许侧移而不把镜头延迟误当移动方向。方向经归一化、有限力/功率控制，不直接写位置或瞬间切换水平速度。

地面跳跃为模板规则的有限冲量并支付电池能量，不代表完整模型关节动力学；保持Space随后进入有限喷射。独立推进余量表示推进持续使用裕量，与电池焦耳和武器热量分开，空中不能回复，落地回正后恢复。参数从MOVEMENT_RULES公开，改变规则必须再升级版本。

网页使用Q推进以保留浏览器Ctrl+W行为。Shift仅缓行，不缩小碰撞体，不将其称作完整蹲伏。参考不是原作数值复刻；EXVS锁定/step/攻击取消另行设计。

代价是仍使用稳定胶囊与规则动作、缺少真实双足姿态/客户端预测。本决定不更改MuJoCo机械试验台与Rapier比赛的边界，也不认证全部设备手感。
