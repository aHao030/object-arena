# M14: 使用鼠标观察与瞄准

**Status:** in-progress

**Spec:** .scratch/mecha-arena/mouse-look-spec.md

**Blocked by:** none

**What to build:** 单击战场/按钮启用鼠标视角，Esc退出；右键拖动作为不锁光标的路径。机库与驾驶均可观察，沿用服务器判定与触屏操作。

- [x] 真实鼠标意图→服务器转向/移动方向、限速和异常输入红绿回归。
- [x] 右键拖动及机库/驾驶画面已实测；捕获、退出/失焦等DOM边界完成回归。
- [ ] 在允许Pointer Lock的真实浏览器完成成功捕获/原生Esc释放验收（内置浏览器拒绝，右键路径已可用）。
- [x] 类型/完整测试/构建/界面检查与双轴独立复核；审查后画布替换回归单独验证通过。
- [ ] 提交、私有仓库推送与日志。

失败场景：浏览器拒绝Pointer Lock时有可用的右键路径；触屏不误捕获鼠标；极值不能绕过物理转向上限；离房、失焦、卸载不留下监听/按住输入。
