# 组合驾驶与 Q/E/R/T 技能槽增量

用户最终确认：WASD移动、鼠标视角、Space升空、Shift加速、鼠标左键射击；Q/E/R/T技能槽，玩家可自行改键。Space短按起跳、保持后有限喷射，覆盖此前仅跳跃的中间提议。固定审查基点659e694fc8329d7526c48e54f6f5cc9241d91d45。沿用已确认的用户动作→输入帧→真实Rapier快照验证边界。

1. 左右Shift均推进，不再缓行；Space短按起跳、保持后受限升空；C保留缓行。WASD、鼠标、跳跃、推进、射击独立，可并发。
2. 四个技能槽默认Q/E/R/T，均未装备、禁用且不发送能力指令。仅鼠标左键默认射击，移除Q/F射击与E升空的旧键位。具体后续装备待用户指定，不把按钮当已实现武器。
3. 释放一个键或鼠标来源不能清除其他仍按住的动作；对角推进不能绕过速度预算，并发不能绕过电池、推进余量、武器热与射速。失焦、离场和退出锁定继续安全清理。
4. 保留触屏按钮与现有Astryx界面。先点战场再驾驶；输入框、滑杆和界面按钮保留自身键盘焦点行为，浏览器Ctrl/Meta/Alt快捷键不被占用。
5. 不修改比赛协议、物理参数、CP或mecha-slice-0.3。仅改变客户端键位与技能槽展示。仍无近战、护盾和完整装配。
6. 界面可修改四向移动、跳跃/升空、推进、缓行和四技能槽的单键，保存在当前设备、可恢复默认。冲突键/浏览器保留键拒绝且不改变现有设置；损坏存储回落默认。设置期间发出中性驾驶输入，机体仍受对战和重力影响；明确提示保存失败。方向箭头作为固定备用，不可抢占。鼠标左键固定射击，不在本轮键盘设置范围。

从《高达创战者》借鉴自制模型＋驾驶能力共同决定体验的方向；并发输入与资源约束是本项目适配，不称动画官方PC键位。官方来源见docs/engineering/MOVEMENT-REFERENCES.md。
