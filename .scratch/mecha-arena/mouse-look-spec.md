# 鼠标视角增量规格

用户要求：通过鼠标控制视角。固定审阅基点为本轮开始时HEAD `76b10e51c620eb110ea8b7c36c84dd5ae7b6228f`。

- 单击战场或“启用鼠标视角”按钮后锁定光标，移动鼠标改变水平朝向/俯仰；Esc释放。浏览器拒绝或不支持锁定时明确提示按住右键拖动，并让该路径独立可用。
- 鼠标右移朝右、上移向上看；俯仰沿用−30°到40°、水平连续环绕；大/无效输入不产生NaN或无限旋转。
- 机库原创模型支持鼠标环视；驾驶时相机立即响应，瞄准意图经过现有makeInputFrame送入服务器，机体仍受现有转向/推进/命中约束。规则mecha-slice-0.2不变。
- 键盘、触屏按钮与滑杆继续工作，滑杆跟随鼠标更新。失焦/隐藏/离房/结算/卸载清理鼠标捕获与按住输入，避免光标被困。
- 兼容俯视模式的地图随水平视角转动，仰角仅影响瞄准；不把2D称成3D。
- 仅修改输入、场景控制、操作提示及相关规格/任务/日志；不添加依赖或重做视觉。通过类型、真实输入→Rapier行为回归、完整构建检查与Standards/Spec独立复核后提交现有私有仓库。

验证沿用已有“前端用户动作→makeInputFrame→真实Rapier快照”公开seam，覆盖方向与服务器限速；浏览器验证实际捕获/退出与画面变化。此前浏览器限制不作为本轮已完成视觉验收的证据。
