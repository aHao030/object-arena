# 01: 两个设备进入同一个私密房间

**What to build:** 电脑和手机从页面加入同一房间，显示一致的预置物体、玩家状态和加载结果。

**Blocked by:** None (can start immediately)

**Status:** superseded

+- [ ] 同一账号不能冒充另一玩家；房间限两名参与者，旁观权限明确关闭。
- [ ] 双方确认相同冻结资源后才能准备；超时取消且显示原因。
- [ ] 持续连接与房间状态可用两个浏览器验证，界面不要求触屏设备使用键盘。
